# Odin Recipes

A simple recipe website created as the first project in **The Odin Project** curriculum.  

This project demonstrates the fundamentals of HTML, including:

- Semantic structure using `<main>` and `<section>`  
- Proper heading hierarchy (`<h1>` → `h2`)  
- Unordered and ordered lists for ingredients and steps  
- Image inclusion with descriptive alt text  
- Navigation between pages using relative links
